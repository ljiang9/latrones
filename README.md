# Latrones 古罗马军棋

古罗马军棋（Ludus latrunculorum，拉丁语"强盗游戏"）的**重构版实现**。
真实历史规则已经失传，这里采用学界常见的重构规则；README 末尾诚实说明了
与正史的差异。

## 玩法

- 8×8 棋盘，双方各 16 子，开局摆在己方底线两行（甲在上、乙在下）。
- 棋子像国际象棋的车：横走或竖走任意格，不能跳过棋子。
- **夹吃（custodian）**：走子落定后，若某敌子在横/竖方向上被你的两子
  紧邻夹住（落子—敌子—己子），该敌子被吃掉。
- 主动走进两敌子之间**不算**自杀（只有走子方能造成吃子）。
- 吃光对方全部棋子，或对方轮到行棋时无合法走法，即获胜。

## 用法

```bash
python -m latrones                 # 人机对战（回合制，需终端）
python -m latrones --auto          # AI 对 AI 自动演示（默认 10 局）
python -m latrones --auto --games 20 --seed 7 --verbose
```

交互走法输入如 `1,3 5,3`（把 (1,3) 走到 (5,3)），`q` 退出。

## AI

贪心策略：优先吃子最多的走法；无吃子时走靠近敌子的走法；
平局按 `--seed` 随机打破。不会深层搜索，熟悉规则的人类通常能赢。

## 已知局限（诚实版）

- **规则是重构的**：Ludus latrunculorum 的真实规则没有完整传世，
  棋盘尺寸、布子数、走法（车走 vs 单格走）、吃子细节在各重构版本中
  都不一样。本项目取的是最常见的 8×8 / 16 子 / 车走 / 夹吃版本，
  不要把它当成"正史规则"。
- AI 只是贪心启发式，不做深层搜索。
- 对局设 600 半回合上限防无限互绕，撞上限判和棋。
- 文本回合制界面，无图形/存档/悔棋；Python 3.10+，纯标准库。
